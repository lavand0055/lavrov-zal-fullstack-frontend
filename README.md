# Зал — выбор сеанса с учётом качества зала

Простой адаптивный сайт для выбора киносеанса не только по фильму и цене, а по качеству конкретного зала (звук, температура, чистота, удобство).

## Страницы

- `index.html` — главная с ближайшими сеансами и статистикой
- `sessions.html` — список сеансов с поиском и фильтрами
- `hall.html` — карточка зала + оценки + форма отзыва
- `profile.html` — профиль пользователя и сохранённые оценки

## Реализованные функции

- Семантическая HTML-разметка
- Единый тёмный стиль (CSS-переменные)
- Адаптив (десктоп + мобилка, бургер-меню)
- Поиск и фильтрация сеансов
- Модальные окна (фильтры и оценка зала)
- Валидация форм
- Сохранение данных в localStorage
- Навигация между страницами

## Технологии

- HTML5
- CSS3 (без фреймворков)
- Vanilla JavaScript

## Как запустить

Открой `index.html` в браузере или залей на GitHub Pages.
